# ML Text Tokenization

This repository contains the text tokenization exercise from the notebook.

## What this exercise covers

The exercise demonstrates how text can be converted into numbers that a machine learning system can work with:

- cleaning text
- splitting text into tokens
- building a vocabulary
- encoding words as numeric token IDs
- decoding numeric IDs back into words

The example text is:

`How are you today?`

## Notebook

Open `notebook.ipynb` to run the exercise.

## Requirements

Install the dependencies with:

```bash
pip install -r requirements.txt
```
